# note-keeper-223402-223413

This workspace contains the React frontend for the Note Keeper application.

- App location: `frontend_web`
- Run:
  1. `cd frontend_web && npm install`
  2. Optionally set `REACT_APP_API_BASE=http://localhost:3001` in `.env`
  3. `npm start` → http://localhost:3000

The app communicates with the FastAPI backend at http://localhost:3001 (see the sibling workspace `note-keeper-223402-223412/backend_api`).
